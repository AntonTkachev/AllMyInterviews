### Python

- **functools.lru_cache** — встроенный декоратор для кэширования результатов функции (LRU).
- **Dask** — библиотека для параллельной обработки больших данных, аналог Pandas.
- **@contextmanager** — декоратор из `contextlib` для создания контекстных менеджеров.
- **Декоратор** — функция, изменяющая поведение другой функции.
- **Cache** — общий термин; может означать кэш-переменную, структуру или концепцию.
