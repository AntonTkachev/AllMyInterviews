# Уровни Raw и Staging в процессе обработки данных

В процессе ETL (Extract, Transform, Load) данные обычно проходят через несколько уровней, включая **Raw** и **Staging**, перед тем как попасть в основное хранилище данных (например, Data Warehouse) для аналитики.

## 1. Raw уровень

**Raw уровень** — это начальная точка для хранения сырых данных, как они поступают из источников. Эти данные обычно сохраняются в том виде, в каком они были получены (например, JSON, CSV или другие форматы), без значительных изменений или обработки. Цель этого уровня — сохранить исходные данные для возможного восстановления или повторной обработки.

Пример:
- Загрузка логов веб-серверов или других данных, как они есть, в Delta таблицы.

## 2. Staging уровень

На **Staging уровне** происходит первичная очистка и трансформация данных. Здесь данные очищаются от дубликатов, исправляются ошибки, стандартизируются форматы (например, временные метки приводятся к единому виду), и данные подготавливаются для дальнейшего использования.

**Важно**: На Staging уровне мы не работаем с исходными сырыми файлами, а используем данные, сохраненные на **Raw уровне** в виде таблиц.

Пример:
- Очищенные данные из Raw уровня, например, удаление дубликатов, нормализация временных меток, преобразование форматов.

## Процесс:

1. **Raw уровень**: Сырые данные сохраняются в Delta таблицах.
2. **Staging уровень**: Данные из Raw уровня очищаются и подготавливаются для загрузки в основной слой данных.

## Заключение

Использование уровней **Raw** и **Staging** помогает разделить процесс обработки данных на два этапа:
- На **Raw уровне** сохраняются необработанные данные, которые могут быть использованы позже.
- На **Staging уровне** данные очищаются и подготавливаются для дальнейшего анализа.

Такой подход улучшает производительность, позволяет гибко управлять данными и поддерживать их целостность на протяжении всего процесса обработки.

## Bronze/Silver/Gold layers

Бронза / Серебро / Золото - это слои в Data Lake, пример как организовать Data Lake:

- Бронза - первичный прием
- Серебро - отфильтрованные и очищенные данные
- Золото - агрегированные данные бизнес-уровня
