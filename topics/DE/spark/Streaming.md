# **Spark Streaming**

**Spark Streaming** — это расширение Spark, обеспечивающее **масштабируемую, отказоустойчивую потоковую обработку**
данных в реальном времени.  
Данные могут поступать из **Kafka, Kinesis, TCP**, обрабатываться с использованием **SQL, ML, GraphX**, а затем
записываться в **файловые системы, базы данных и мониторинговые панели**.

## **Архитектура Spark Streaming**

- **Engine** – обрабатывает SQL-запросы и управляет выполнением.
- **REST API** – предоставляет доступ к движку через HTTP.
- **CLI** – консольный интерфейс для управления стриминг-приложениями.
- **Web UI** – позволяет мониторить и настраивать потоковые задачи.

## **Spark Watermark**

**Watermark** определяет порог ожидания поздних событий.

- Если событие **пришло в пределах водяного знака**, оно учитывается.
- Если **пришло позже**, оно **игнорируется**.

**Используется для работы с out-of-order данными** в потоках.

## **Spark Checkpointing**

**Механизм восстановления состояния** после сбоев.

### **Виды чекпоинтов**:

- **Метаданные** – хранят конфигурации, операции и состояние выполнения.
- **Данные** – сохраняют промежуточные результаты (например, в HDFS/S3).

📌 **Преимущества:**

- **Восстановление после сбоев** – обработка продолжается с последнего сохранённого состояния.
- **Сохранение метаданных** – Spark помнит, какие данные уже обработаны.
- **Производительность** – оптимизирует работу со стейтфул-обработкой.

---

## **KStream vs KTable**

- **KTable** – разделяет данные между экземплярами Kafka Streams.
- **GlobalKTable** – содержит **полную копию** всех данных в каждом экземпляре (больше памяти, но доступ без ключа).
- **KStream-GlobalKTable Join** – позволяет соединять поток с таблицей по неключевому атрибуту.

**ksqlDB** – SQL-надстройка над Kafka Streams для аналитики потоковых данных.

---

## **📌 Output Modes в Spark Streaming**

Определяют, какие данные записывать в приёмник:

| **Режим**                                | **Описание**                                     |
|------------------------------------------|--------------------------------------------------|
| **Append** (`.outputMode("append")`)     | Записывает **только новые строки**.              |
| **Complete** (`.outputMode("complete")`) | Записывает **все строки**, если есть обновления. |
| **Update** (`.outputMode("update")`)     | Записывает **только обновлённые строки**.        |

🎯 **Вывод:**

- **Spark Streaming** — мощное решение для потоковой обработки с интеграцией Kafka, Kinesis и SQL.
- **Watermark** управляет задержками, **Checkpointing** – восстанавливает процесс после сбоев.
- **Output Modes** контролируют, какие данные попадут в хранилище. 🚀
