# 📊 Мониторинг с Grafana и Prometheus

Мониторинг – ключевой компонент инфраструктуры, который позволяет отслеживать состояние сервисов, предотвращать сбои и
анализировать метрики производительности. Одним из самых популярных стеков для мониторинга является **Grafana +
Prometheus**.

---

## **1️⃣ Prometheus – сборщик метрик**

### 🔹 Что такое Prometheus?

**Prometheus** – это система мониторинга с открытым исходным кодом, разработанная для сбора и хранения временных рядов
метрик. Он используется для сбора данных с серверов, баз данных, контейнеров, приложений и IoT-устройств.

### 🔹 Ключевые особенности:

- **Pull-модель сбора данных** – Prometheus сам опрашивает сервисы (targets).
- **Хранение метрик в виде временных рядов** (time-series database).
- **PromQL** – мощный язык запросов для анализа метрик.
- **Автодискавери** – автоматически обнаруживает новые сервисы.
- **Алерты и интеграция с Alertmanager**.

### 🔹 Архитектура Prometheus

1. **Prometheus Server** – основной компонент, собирающий метрики через HTTP.
2. **Exporters** – агенты, которые передают метрики в формате Prometheus.
3. **Pushgateway** – позволяет передавать метрики из кратковременных задач.
4. **Alertmanager** – отправляет алерты в Slack, Telegram и другие каналы.

---

## **2️⃣ Grafana – визуализация метрик**

### 🔹 Что такое Grafana?

**Grafana** – это инструмент для визуализации данных, который позволяет строить дашборды и анализировать метрики из
различных источников, включая **Prometheus, Elasticsearch, InfluxDB, MySQL, AWS CloudWatch и другие**.

### 🔹 Ключевые возможности:

- **Гибкая настройка дашбордов** с графиками, таблицами и алертами.
- **Интеграция с Prometheus** для анализа метрик в реальном времени.
- **Настройка алертов** с отправкой уведомлений в Slack, Telegram, Email.
- **Role-based access control (RBAC)** – управление доступом.
- **Плагины и интеграция с множеством источников данных**.

### 🔹 Архитектура Grafana

1. **Datasource (источник данных)** – Prometheus, Loki, Elasticsearch и др.
2. **Dashboard (дашборды)** – визуализация метрик в виде графиков.
3. **Alerting (алерты)** – триггеры на основе метрик.
4. **Plugins (плагины)** – расширение функционала Grafana.

---

## **3️⃣ Как настроить мониторинг с Grafana и Prometheus?**

### **1. Установка Prometheus**

Prometheus можно развернуть в Kubernetes, Docker или на сервере:

```bash
docker run -p 9090:9090 prom/prometheus
```

### **2. Добавление Exporters**

Для сбора метрик из сервисов используются **экспортеры**, например:

- **Node Exporter** – метрики ОС (CPU, память, диски).
- **Blackbox Exporter** – мониторинг доступности сервисов.
- **Kafka Exporter** – метрики Kafka.

### **3. Установка Grafana**

Grafana также запускается в Docker:

```bash
docker run -d -p 3000:3000 grafana/grafana
```

### **4. Подключение Prometheus к Grafana**

1. В Grafana добавляем новый **Data Source**.
2. Выбираем **Prometheus** и указываем URL [**http://localhost:9090**](http://localhost:9090).
3. Создаём дашборды с метриками.

---

## **4️⃣ Настройка алертов в Prometheus и Grafana**

### **Алерты в Prometheus**

Для отправки уведомлений используется **Alertmanager**. Пример алерта при высокой загрузке CPU:

```yaml
alerting_rules.yml:
group:
  - name: CPU Alerts
    rules:
      - alert: High CPU Usage
        expr: avg(rate(node_cpu_seconds_total[1m])) > 0.85
        for: 5m
        labels:
          severity: critical
        annotations:
          summary: "Высокая загрузка CPU"
```

### **Алерты в Grafana**

В Grafana можно настроить алерты через UI:

1. Открываем **Edit Panel**.
2. Включаем **Alerting**.
3. Настраиваем триггеры (например, если CPU > 85%).
4. Отправляем уведомления в Slack, Telegram, Email.

## **5️⃣ Когда использовать Grafana и Prometheus?**

| Сценарий                       | Prometheus | Grafana                  |
|--------------------------------|------------|--------------------------|
| Мониторинг серверов            | ✅          | ✅                        |
| Мониторинг Kubernetes          | ✅          | ✅                        |
| Настройка алертов              | ✅          | ✅                        |
| Анализ логов                   | ❌          | ✅ (Loki)                 |
| Долговременное хранение метрик | ❌          | ✅ (InfluxDB, ClickHouse) |

💡 **Prometheus – мощный инструмент для сбора метрик, а Grafana – для визуализации и аналитики!** 🚀
