**Аспектно ориентированное программирование** — AOП-это метод программирования, который позволяет программистам
модулировать поведение, используемое в типичных подразделениях ответственности, используемых в объектно-ориентированном
программировании. Основная конструкция аспектов AOП – это поведение, применимое к разным классам. Извлечение этих
моделей поведения из отдельных компонентов в аспекты позволяет легко использовать их повторно.

Парадигма программирования предназначенная для декомпозиции — это разбиение сложной проблемы или системы на части,
которые легче представить, понять, запрограммировать и поддерживать.

Реактивное программирование – парадигма программирования, которая основывается на запрограммированных действиях,
запускаемых в связи с событиями, а не на хронологическом порядке кода. Реактивные программы эффективно используют
компьютерные ресурсы и хорошо масштабируются всего несколькими потоками. Его непоследовательная форма позволяет избежать
блокировки стека и поддерживать оперативность реагирования.

Библиотеки:

1. **RxJava** — библиотека для реактивного программирования на Java. Она позволяет создавать асинхронные и
   событийно-управляемые программы. Пример использования:
   ```java
   Observable<String> observable = Observable.just("Hello", "World");
   observable.subscribe(System.out::println);
   ```

2. **Project Reactor** — библиотека для создания реактивных приложений на базе Java 8+. Она поддерживает модель
   реактивного программирования и интегрируется с Spring. Пример использования:
   ```java
   Flux<String> flux = Flux.just("Spring", "Reactor");
   flux.subscribe(System.out::println);
   ```

3. **Akka Streams** — часть фреймворка Akka, которая предоставляет инструменты для работы с потоками данных. Она
   позволяет обрабатывать большие объемы данных асинхронно и с высокой производительностью. Пример использования:
   ```scala
   val source = Source(List("Akka", "Streams"))
   source.runForeach(println)
   ```
