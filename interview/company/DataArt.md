
DataArt

**RDD, DataFrame, Dataset**: RDD - низкоуровневый API для работы с данными, DataFrame - структурированные данные с оптимизациями, Dataset - типизированные DataFrame.

**Spark Shuffle**: процесс перераспределения данных между узлами для выполнения операций, требующих обмена данными.

**Actor System, ZIO2**: Actor System - модель конкурентного программирования, ZIO2 - библиотека для управления эффектами в Scala.

**Scala Types, Type Level, Type Class, Полиморфные программы, Given**: Scala поддерживает типы, уровни типов, классы типов, полиморфизм и контекстные параметры (given).

**Function vs Method**: Функция - объект, который можно присвоить переменной, метод - часть класса или объекта.

**Filter vs FilterWith**: Filter - стандартная функция фильтрации, filterWith - кастомная функция фильтрации с дополнительными условиями.

**SQL Transaction, Уровни изоляции и аномалии транзакций**: Транзакция - единица работы с БД, уровни изоляции - степень видимости изменений, аномалии - проблемы при параллельных транзакциях.

**Профилирование запросов в реляционных БД**: Анализ производительности SQL-запросов для оптимизации их выполнения.
