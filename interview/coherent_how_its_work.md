Deploy Lambda

На проекте мы выбрали AWS Lambda + S3 + Terraform для деплоя кода. Этот подход оказался простым, надёжным и экономичным.

Как это работает:

1️⃣ GitHub Actions отслеживает изменения в main, упаковывает код и загружает .zip в S3.
2️⃣ S3 Versioning хранит все версии .zip, позволяя легко откатываться назад.
3️⃣ Terraform автоматически подтягивает последнюю версию архива из S3 и раскатывает её на Lambda.
4️⃣ Lambda Layers для зависимостей деплоятся аналогично – через отдельный .zip в S3.

Почему именно так?

✅ Нет лишних затрат – Lambda запускается раз в день, значит, платим только за реальное выполнение.
✅ Минимум сложностей – не нужны папки с датами, Terraform всегда берёт актуальную версию.
✅ Простота откатов – если новый код сломался, можно быстро переключиться на предыдущий VersionId в S3.
✅ Автоматизация – вся цепочка от коммита до продакшена работает без ручных действий.

Такой подход позволил нам быстро и стабильно деплоить код, экономя время и деньги.
